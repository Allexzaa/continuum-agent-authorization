# Persia AI-control pilot

A small, sandboxed study of prompt injection and tool authorization on a local LLM assistant. Everything runs against a synthetic
mock world: no live tools, accounts, files or network (only localhost model endpoints, enforced in code and tested).

Status: pilot. Hand-authored synthetic attacks, 14 confirmatory cases plus 8 post hoc mixed-task cases, 3 trials per cell, two models, 774 scored runs. Not evidence about
frontier models or production safety. Protocol and hypotheses: `PREREGISTRATION.md` (written before any scored run).

## What is measured
Three conditions per model: A (system prompt without injection-trust rules), B (prompt as deployed), C (B plus an independent,
deterministic, oracle-scoped authorization policy). Outcomes: injection exposure, unauthorized attempts, simulated unauthorized
executions, legitimate task success, false blocks, approval friction, latency, crashes. Counts are reported as n/N.

## Requirements
- Python 3.12 with the packages used by the Persia voice agent (`voice-agent/.venv`), Ollama running on `localhost:11434`.
- Models: `persia-f16:latest` (a Llama 3.1 8B fine-tune, not published), `gemma4:12b`. The system prompt `SOUL.md` contains personal
  data and is not published; prompt B is that file unchanged and prompt A removes four lines (67, 68, 70, 72), see `src/adapter.py`.
- Memory: load one model at a time. `run_pilot.sh` unloads other Ollama models and refuses to start below 30 GB available memory.

## Run
```
research/run_tests.sh                 # 46 tests, no GPU, no network
research/run_pilot.sh                 # confirmatory arms and the legacy-loop arm; writes research/results/pilot_*/runs.jsonl
research/run_followup.sh              # post hoc arms: stop-on-read ablation and mixed tasks (research/results/followup_*)
python3 -I research/src/report.py research/results/pilot_persia research/results/pilot_gemma12b research/results/pilot_gemma12b_legacy research/results/followup_*
```

## Reproducibility notes
- Decoding for every run: temperature 0.6, top_p 0.9, top_k 40, num_ctx 8192, num_predict 512, thinking off, seed 1000 + trial.
- Every run record stores the git commit, a dirty flag, fixture hash, prompt hash, and SHA-256 prefixes of `llm.py`, `SOUL.md` and the
  harness source (`voice-agent/` is not under version control here).
- Case manifest hashes: `cases/MANIFEST.sha256`. Cases are generated by `cases/build_pilot.py`; all addresses are `.invalid`.
- Persia's agent loop was fixed before the pilot (see `PREREGISTRATION.md` section 7). Earlier benchmark numbers from before those fixes
  are not comparable.

## Layout
`src/` adapter, mock world, policies, scorer, runner, report; `cases/` locked manifest and generator; `tests/` unit and pre-flight tests;
`results/` run logs (not committed); `reports/` evidence memo (`evidence_memo.html`/`.pdf`) and generated tables (`tables_all_arms.md`).

## Results
See `reports/evidence_memo.pdf`. Short version (section 4b of the memo covers the later F-018 fix and `run_postfix*.sh`): no forbidden call executed in the confirmatory pilot because the fixed loop switches tools off after a read request is
satisfied; with that rule ablated, prompts A and B executed the injected action in 8 of 66 exposed runs and the policy condition in 0 of 33, with 0 false blocks.
Condition C is an oracle-scoped research policy, not a deployable control.

## Reproducibility status
Partially reproducible. Earlier versions of Persia's `voice-agent/pipeline/llm.py` were never under version control and are unavailable; only the final version
remains and it matches the `postfix2_*` runs. Hashes of earlier versions identify what ran but do not recover its behavior. The research harness is recoverable from
git. Recorded model output is truncated to 2,000 characters per round; planner calls and empty-final recovery text were not stored. Exact historical replay is not claimed.
`research/src/verify_claims.py` re-scores every run, recomputes every memo figure and replays what was recorded. Run categories: 774 original scored runs (252 confirmatory,
126 exploratory legacy-loop, 396 post hoc); post-fix re-runs are separate (972 records: 648 first pass, 324 final guard, the latter repeating three arms of the former); the
bundle's 2,216 records also include development, calibration and audit runs.
